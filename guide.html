1.1 LabVIEW 是什么？（给完全没听过的人）

LabVIEW（读作"莱布维尤"）的全称是 Laboratory Virtual Instrument Engineering Workbench —— 实验室虚拟仪器工程工作台。它由美国 NI（National Instruments）公司于 1986 年发布，至今已发展近 40 年。

🔑 最大的特点：用「图」编程，不是用「字」编程

传统编程语言（C / Python / Java / C#）是这样的：你要在文本编辑器里一行一行敲代码，用字母、数字和符号表达逻辑。代码写错了标点符号，程序就报错。

LabVIEW 是这样的：你在一个白色画布上放置功能方块（函数），然后用彩色的线把它们连起来。就像画电路图或者画流程图一样。你不写任何文字代码。

类比：C 语言 = 写作文（用文字表达想法） → LabVIEW = 画流程图（用图形表达逻辑）

1.2 LabVIEW 在实际工作中用来做什么？

行业具体应用原因
🔋 电池/新能源电池充放电循环测试、容量标定、内阻测量、BMS验证、电池分容柜控制支持所有品牌电源和电子负载的程控驱动，开发速度快
🏭 产线自动化ATE(FCT/ICT)测试站、电路板自动检测、产品出厂质量检验快速搭测试序列，可集成扫码枪、PLC、气动治具
🔬 实验室科研多通道同步采集温度/压力/振动/应变/电压/电流数据，实时分析与绘图与NI采集卡(DAQ)即插即用，无需写底层驱动
📡 仪器程控程控电源、电子负载、万用表、示波器、频谱仪、信号发生器VISA统一接口，SCPI通用命令，一套代码控所有仪器

💿 如何下载、安装、启动 LabVIEW

▼

2.1 选择正确的版本

版本价格适合谁限制
Community Edition（社区版）🆓 免费✅ 学生、自学者、个人项目不可用于商业盈利项目
Professional Edition（专业版）付费企业、商业项目需购买许可证
Evaluation（试用版）🆓 试用短期评估（45天）45天后过期
学这本教材用 Community Edition（社区版），完全免费，功能足够学到独立做项目的水平。建议选 2023 Q1 或更新版本。

2.2 下载步骤（一步步跟着做）

  1. 打开 NI 官网：浏览器输入 www.ni.com，回车。页面是全英文的，可以用浏览器的翻译功能（右键→翻译成中文）。
  2. 找到下载入口：在页面顶部搜索框中输入 LabVIEW Community Edition download，回车搜索。点击搜索结果中标题为 "Download LabVIEW Community Edition" 的链接。
  3. 注册 NI 账号（如果没有的话）：点击 Download 后会要求登录。没有账号就点击 "Create an account"。用你的邮箱注册（推荐用常用邮箱）。填写姓名、邮箱、密码，点击注册。去邮箱点击 NI 发来的验证链接完成验证。这是免费的。
  4. 选择版本：登录后，选择 LabVIEW Community Edition 对应的版本号（如 2023 Q1），选择操作系统为 Windows，点击 Download。浏览器会开始下载一个约 2-3 GB 的安装包（文件名类似 ni-labview-community-2023-x86.exe）。
  5. 等待下载完成：文件很大，根据网速需要 10-60 分钟不等。

2.3 安装步骤（每一步都有截图说明）

  1. 双击安装包：找到下载好的 .exe 文件，双击运行。如果弹出「用户账户控制」窗口，点击「是」允许运行。
  2. 选择安装路径：安装向导启动后，第一个界面是欢迎页面，直接点 Next。然后会让你选择安装路径。建议使用默认路径：C:\Program Files\National Instruments\，不要改成中文路径（中文路径可能导致后续问题）。点 Next。
  3. 选择要安装的组件（重要！）：你会看到一个组件列表，每个组件旁边有勾选框。初学阶段建议勾选以下组件：
    ☑ LabVIEW 2023 Community Edition（主程序，必须选）
    ☑ NI-DAQmx（数据采集驱动，强烈建议装上）
    ☑ NI-VISA（仪器通信驱动，强烈建议装上）
    ☑ NI MAX（设备管理器，会自动安装）
    其他组件可以不勾选，以后随时可以通过 NI Package Manager 补充安装。
  4. 接受许可协议：勾选 "I accept the license agreements"，点 Next。
  5. 等待安装：安装过程需要 20-60 分钟。进度条会逐个组件安装，中间可能会弹出命令行窗口，不要关掉。安装过程中电脑可能会重启一到两次——这是正常的，重启后会继续安装。
  6. 完成安装：所有组件安装完成后，点击 Finish。桌面上不会自动创建快捷方式，需要从开始菜单打开。
安装过程中一定要关闭杀毒软件（如360、腾讯电脑管家），否则可能误拦截某些组件导致安装失败。安装完再打开杀毒软件。

2.4 第一次启动 LabVIEW

  1. 点击 Windows 开始菜单（左下角 Windows 图标）
  2. 在搜索框中输入 LabVIEW
  3. 在搜索结果中找到 "NI LabVIEW 2023"（版本号可能不同），点击打开
  4. 首次启动可能需要 30 秒到 1 分钟加载，这是正常的
  5. 启动后会弹出 Getting Started 窗口——这就是 LabVIEW 的主入口
  6. 如果弹出登录窗口，社区版用户用注册的 NI 账号登录即可激活
✅ 启动成功标志：看到 Getting Started 窗口，左侧有 New / Open 等选项，右侧有 News 和 Learning 资源推荐。如果能正常显示这个窗口，说明安装和激活都成功了。

3.1 两个窗口的关系（这是理解 LabVIEW 的关键）

在 Getting Started 窗口点击 Blank VI，你会同时看到两个窗口出现：

🟫 前面板 (Front Panel)⬜ 程序框图 (Block Diagram)
背景色灰色白色
作用用户界面：放按钮、输入框、图表程序逻辑：放函数、连线、结构
给谁看最终用户 / 操作员开发者 / 你自己
右键打开控件选板 Controls Palette函数选板 Functions Palette

🔑 用汽车类比：

前面板 = 仪表盘（方向盘、速度表、空调按钮）——是驾驶员操作的地方。
程序框图 = 发动机舱（引擎、电路、油管）——是修车师傅工作的地方。
按 Ctrl+E 在两者之间切换。

3.2 工具栏按钮完全解释

按钮快捷键功能说明
▶ Run（运行）Ctrl+R执行程序。如果箭头断裂（显示为灰色齿轮图标），说明程序有错误，点击断裂箭头查看错误列表
🔄 Run Continuously—反复运行程序。修改参数后自动反映到运行中。测试阶段常用
⏹ Abort（强行停止）Ctrl+.暴力中止程序。尽量避免使用，最好在程序中设计正常的停止按钮
⏸ Pause（暂停）—暂停运行，可以检查各变量的当前值。再点一次继续运行
💡 Highlight Execution—⭐⭐⭐ 调试神器。数据以气泡动画沿连线流动，慢速展示每一步的执行过程。适合「我不理解这段代码在干什么」的时候
📌 Retain Wire Values—保留上次运行后每根连线的数据值，配合探针(Probe)使用
📐 Align Objects—将选中的控件对齐——左对齐、右对齐、居中对齐、等距分布等。让前面板看起来专业
🧹 Clean Up Diagram—自动整理程序框图的连线位置。写得乱的时候点一下能好很多

✍️ 动手写第一个 LabVIEW 程序：加法器

▼

4.1 目标

创建一个 VI：用户在两个输入框中输入数字 → 程序自动计算两数之和 → 结果显示在屏幕上。目标不是"加法器"本身，而是学会 放控件 → 加函数 → 连线 → 运行 这个完整流程。

4.2 逐步骤操作

第 1 步：新建 VI

  1. 在 Getting Started 窗口点击 Blank VI
  2. 你会看到两个窗口：一个灰色背景（前面板）和一个白色背景（程序框图）
  3. 这两个窗口是叠在一起的，可以用 Ctrl+E 切换，也可以把它们拖开

第 2 步：在前面板放置两个输入框

  1. 确保你在灰色前面板（不在的话按 Ctrl+E）
  2. 在灰色空白区域右键→ 弹出控件选板
  3. 找到 Numeric → Numeric Control（图标是一个小数字框，旁边有上下箭头）
  4. 点击 Numeric Control 后，鼠标会变成一个小手+控件虚影
  5. 在灰色面板的左侧点击一下，控件就放到面板上了
  6. 控件上有一个标签 "Numeric"。双击这个标签文字，输入新名字："数字 A"
  7. 重复 2-6 步，再放一个 Numeric Control，改名为 "数字 B"
  8. 拖拽控件调整位置，让 "数字 A" 在上面，"数字 B" 在下面

第 3 步：在前面板放置结果显示框

  1. 在前面板空白处右键 → Numeric → Numeric Indicator（Indicator 和 Control 的区别：Indicator 背景偏灰，只能显示不能输入）
  2. 放在 "数字 B" 的下方
  3. 双击标签改名为 "结果 C"
Numeric Control（输入控件）= 用户能修改值，边框较粗，图标在程序框图中边框粗（数据源）。Numeric Indicator（输出显示）= 用户不能修改，边框较细，图标边框细（数据接收方）。

第 4 步：切换到程序框图

按 Ctrl+E 切换到白色程序框图。你会看到三个彩色图标——它们对应前面板上的三个控件。两个边框粗的（数字A、数字B）和一个边框细的（结果C）。

第 5 步：添加加法函数

  1. 在白色程序框图空白处右键→ 弹出函数选板
  2. 找到 Numeric → Add（三角形图标，中间有个加号 +）
  3. 点击放置到程序框图中，放在输入和输出图标之间

第 6 步：连线（最关键！）

  1. 把鼠标移到「数字 A」图标右侧的小三角形端子（端子会高亮）
  2. 当光标变成线轴图标（线圈）时，按住鼠标左键，拖动
  3. 一条橙色虚线会跟随鼠标。把它拖到 Add 函数左上角的端子（标着 x）
  4. 松开鼠标，橙色实线出现——连接成功！
  5. 同样方法：把「数字 B」连到 Add 函数左下角端子（标着 y）
  6. 把 Add 函数右侧输出端子连到「结果 C」的输入端
  7. 按 Ctrl+B 清除可能的断线，确保所有线都是实线

🔑 什么是对的和错的连线？

✅ 正确：橙色实线 = 连线成功，浮点数类型
✅ 正确：蓝色实线 = 整数类型
❌ 错误：黑色虚线 = 断线，类型不匹配或连错地方了
✅ 一键修复：Ctrl+B 删除所有断线

第 7 步：整理和保存

  1. 点击工具栏上的 Clean Up Diagram 按钮（扫帚图标），自动整理连线和位置
  2. 按 Ctrl+S 保存。文件名："加法器.vi"，保存到桌面的 labview-course 文件夹

第 8 步：运行验证

  1. 按 Ctrl+R 或点击工具栏上的 ▶ 运行按钮
  2. 在「数字 A」输入框中输入 8
  3. 在「数字 B」输入框中输入 5
  4. 观察「结果 C」——它应该自动显示 13
  5. 用鼠标点击「数字 A」旁边的上下小箭头，值会以步长 1 增减。观察「结果 C」是否同步变化
  6. 试试输入小数：A=3.14, B=2.86 → 结果应该是 6.00
🎉 恭喜！你完成了人生中第一个 LabVIEW 程序！虽然很简单，但这就是所有 LabVIEW 程序的基本骨架——前面板放控件，框图放函数+连线。

4.3 自己动手改造（这些练习很重要）

✏️ 改造练习

  1. 改成乘法器：把 Add 函数换成 Multiply（右键 → Numeric → Multiply），重新连线，试运行
  2. 改成三数相加：前面板放 3 个输入框，程序框图用两个 Add 函数：第一个加 A 和 B，第二个把第一个的结果加上 C
  3. 加一个指示灯：在前面板放一个 Round LED（右键 → Boolean → Round LED）。程序框图中，把 Add 的输出用 Comparison → Greater? 和常量 100 比较，比较结果（绿线）连到 LED。当结果 >100 时灯亮

🔗 连线与数据流：程序怎么「跑」起来

▼

7.1 数据流执行规则（LabVIEW 最核心的概念）

🔑 黄金规则：一个节点只有在所有输入端都收到数据后才开始执行。

推论：

  • 如果 A 的输出连到了 B 的输入 → A 一定先于 B 执行
  • 如果 C 和 D 之间没有任何连线 → C 和 D 同时并行执行
  • 这意味着 LabVIEW 程序「天然多线程」——不需要你写任何多线程代码

7.2 连线规则

规则说明
一个输出可连多个输入一根线可以分叉（Branch）连到多个地方
一个输入只能接一根线不能把两根线连到同一个输入端
类型必须匹配橙色(DBL)不能直接连蓝色(I32)端子，需要转换
不能形成环A→B→C→A 的数据流环不被允许

7.3 怎么控制执行顺序？（三种方法，优先级从高到低）

🥇 方法一：数据依赖（最佳）

A 的输出数据是 B 的输入 → A 自然先于 B。用数据关系控制顺序，不额外加结构。

// B 需要 A 的结果才能执行
[A]──数据线──→[B]
// A 先执行，B 等 A 完成

🥈 方法二：Error 簇串联（推荐）

把 Error Out → Error In 串起来。既控制顺序，又实现错误处理，一举两得。

// Error 链 = 执行顺序链
[A]──Err──→[B]──Err──→[C]
// 顺序：A → B → C

🥉 方法三：Flat Sequence（不推荐，但有时必须用）

把代码放在不同的 Frame 中，从左到右依次执行。破坏了并行性，能不用就不用。只在一种情况下用：需要确保前面板已经完成更新后才执行下一步。

7.4 常见连线错误及解决

问题现象解决方案
断线（黑色虚线）线上有红色 X，Run 箭头断裂Ctrl+B 删除断线。检查两端数据类型是否一致。添加转换函数
需要连的端子太多线缠成一团用 Bundle/Unbundle By Name 减少连线数
连线方向不对线绕了一大圈重新排列节点：输入端在左，输出端在右

8.1 For 循环 —— 「重复做 N 次」

在程序框图右键 → Structures → For Loop，在空白区域拖出一个矩形框。

关键端子：

  • N（左上角）：循环总次数。不接值 = 自动根据输入数组长度决定
  • i（左下角）：当前迭代计数，从 0 开始

手把手例子：计算 1+2+3+...+100

  1. 放一个 For Loop。N 端子右键 → Create Constant，输入 100
  2. 在循环边框右键 → Add Shift Register（边框上出现两个小三角）
  3. 左侧移位寄存器右键 → Create Constant，输入 0（初始值）
  4. 循环体内：放 Add 函数。上输入 = 左侧移位寄存器，下输入 = i+1（用 Increment 函数给 i 加 1，因为 i 从 0 开始）
  5. Add 的结果连到右侧移位寄存器
  6. 循环结束后，左侧移位寄存器的最终值 = 5050（1到100的和）

自动索引（最重要的特性）：

当数组连入/连出 For 循环时，隧道默认开启自动索引——数组逐元素进入循环、结果自动组装回数组。右键隧道可以切换模式。

8.2 While 循环 —— 「条件满足才停」

For 循环While 循环
什么时候停执行了 N 次后条件端子为 True 时（可设置）
最少执行次数0 次（N=0 时）至少 1 次
适用场景已知次数的重复未知次数的持续运行
While 循环至少执行一次！这意味着停止条件一开始为 True 的情况下循环也会先运行一次。如果这是一个问题，在循环体内第一行用 Case 结构判断是否需要执行。

8.3 Case 结构 —— 「如果...就...否则...」

右键 → Structures → Case Structure。顶部的 ? 端子 是选择器，决定走哪个分支。

  • 选择器接布尔值 → True / False 两个分支
  • 选择器接枚举 → 每个枚举值一个分支 ← 最推荐！
  • 始终设置 Default 分支：右键分支标签 → Make This Case Default

8.4 Event 结构 —— UI 事件处理的核心

Event 结构必须放在 While 循环内，等待用户的界面操作：

// Event 结构的标准使用模式：
While Loop
  └─ Event Structure
       ├─ "按钮1": Value Change → 处理按钮1被点击
       ├─ "数值框": Value Change → 处理数值被修改
       ├─ Timeout (100ms) → 定时刷新显示
       └─ "前面板关闭": Panel Close? → 清理退出
Event 结构 + While 循环 = 事件驱动型程序的基础。在 Event 的 Value Change 事件里不要放耗时操作（串口通信、文件读写）——只发消息，让消费者循环去执行。这就是生产者-消费者模式的来源。

8.5 移位寄存器：循环间的「记忆」

在循环边框右键 → Add Shift Register。

  • 左侧↓箭头 = 上一次迭代的输出（首轮 = 初始值）
  • 右侧↑箭头 = 本次迭代的值传给下一次
  • 拖下边框可创建多层，保留前 N 次的值

经典应用：累加器、求最大值/最小值、状态机存储当前状态、滑动窗口数据缓冲。

  2. 用 While 循环 + 停止按钮做一个持续运行的程序

9.1 数组（Array）：同类数据的集合

数组在 LabVIEW 中用粗边框表示。1D 数组 = 一列表格，2D 数组 = 多行多列表格。

创建数组的两种方法：

  1. 前面板创建：右键 → Array, Matrix & Cluster → Array（这是一个空壳）。然后从 Numeric 中拖一个 Numeric Control 或 Indicator 放入壳内。壳 + 内容 = 数组控件
  2. 程序框图创建：用 Build Array 函数把多个元素合并。右键可切换 Concatenate Inputs（拼接数组）模式

核心数组函数实操：

任务用什么函数怎么用
取出第 N 个元素Index Array上输入=数组，下输入=索引。不接索引=取第0个。拖下边框可取多个元素
获取数组大小Array Size输入数组。1D返回一个数（长度），2D返回两个数（行、列）
在数组末尾添加Build Array上输入=原数组，下输入=新元素。输出=加长1的数组
替换指定位置Replace Array Subset数组+索引+新值→修改后的数组（原数组不改变）
搜索元素位置Search 1D Array数组+搜索值→索引（找不到=-1）

9.2 簇（Cluster）：不同类型打包

类比：数组 = 一排同样的盒子，簇 = 一个箱子里面装了不同种类的物品。

创建和使用簇：

  1. 前面板右键 → Array, Matrix & Cluster → Cluster（空壳）
  2. 往空壳里拖入不同类型的控件：一个 Numeric Control（电压）、一个 Numeric Control（电流）、一个 Enum（状态）、一个 String Control（备注）
  3. 给每个元素起有意义的名字（标签）——这很重要！
  4. 程序框图中使用 Bundle By Name（按名打包）和 Unbundle By Name（按名解包）——名字自动出现，不会搞错顺序
强烈推荐使用 Bundle By Name / Unbundle By Name，而不是简单的 Bundle / Unbundle。因为按名字解包不依赖顺序，代码清晰安全。给簇的字段起好名字是关键。

🧱 子 VI：把你的代码变成可复用的积木

▼

11.1 什么是子 VI？为什么要用？

子 VI 就是 LabVIEW 中的函数（Function）。把一段常用的功能封装成一个 VI，保存好。以后在任何地方，把 .vi 文件拖入程序框图即可调用。

类比：Python 的 def func():、C 语言的 void func(){}、LabVIEW 的子 VI。

11.2 创建子 VI 的完整 6 步流程

  1. 写好功能：在一个普通 VI 中把功能调通。比如写一个「摄氏度转华氏度」：F = C × 9/5 + 32。确保运行正确后再封装。
  2. 设计连接器（Connector Pane）：前面板右上角小图标右键 → Show Connector。选择布局模式。推荐 4-2-2-4 模式（上下各4个，左右各2个）。分配原则：左上=主要输入，右上=主要输出，左下=Error In，右下=Error Out。
  3. 绑定端子：点击连接器的一个格子（会变黑），然后点击前面板上对应的控件/显示件。格子颜色变化表示已绑定——橙色格子=数值输入，棕色格子=数值输出，绿色=布尔，粉色=字符串。
  4. 设计图标：右上角图标右键 → Edit Icon。用 4-6 个字概括功能，配简单色块或简笔画。好图标让别人一看就懂这个子 VI 是干嘛的。如「C→F」配红蓝箭头。
  5. 写描述文档：File → VI Properties → Documentation。写清楚功能、输入输出说明。别人用 Ctrl+H 悬停时能看到这段说明。
  6. 保存：文件名要有意义，如 "Convert_C_to_F.vi"，不要用 "subvi_03.vi"。

11.3 子 VI 设计铁律

  1. 必须有 Error In / Error Out：没有例外。这是 LabVIEW 的「通信协议」
  2. 单一职责：一个子 VI 只做一件事。名字里出现了「和」= 该拆成两个
  3. 有意义的文件名：看名字就知道功能
  4. 输入给默认值：未连接时也能运行

  2. 创建「计算平均值」子 VI（输入数组→输出平均值）

🔍 调试与错误处理：让程序可靠运行

▼

13.1 错误簇：LabVIEW 的「神经系统」

错误簇三个字段：Status（布尔：True=有错）、Code（整数：0=正常，非0=错误码）、Source（字符串：错误发生在哪）。

🔑 错误传播机制：

子VI_A → Error Out → 子VI_B → Error In。如果 A 出错：B 检测到 Error In 有错 → B自动跳过所有内部操作 → 错误原封不动从 B 的 Error Out 传出 → 一路传到最顶层 → Simple Error Handler 弹窗提示用户。

13.2 调试三神器（必须学会）

  1. 💡 探针（Probe）：在连线上右键 → Probe。打开探针窗口实时显示该线的数据值。不改代码、不停程序。适用于「数据值不对，但不知道为什么」。
  2. 🔦 高亮执行（灯泡按钮）：数据以动画气泡沿连线慢速流动，直观展示执行顺序和数据传递。适用于「我不知道这段代码到底在做什么」。
  3. ⏸ 断点（Breakpoint）：在节点上右键 → Set Breakpoint。程序运行到此处自动暂停。适用于「程序在某个地方崩了但我不知道在哪」。

🔌 串口通信与仪器控制：让 LabVIEW 和硬件对话

▼

14.1 VISA：统一通信接口

VISA（Virtual Instrument Software Architecture）是 NI 的统一 I/O 接口。一套函数同时支持串口、GPIB、USB、以太网。无论什么接口、什么品牌的仪器，代码结构完全一样。

14.2 串口通信五步法（最重要的实操模板）

  1. VISA Open（打开端口）
    VISA resource name: 填入 "COM3"（你的串口号）。输出 VISA 会话句柄。在 NI MAX 中可以查看电脑上有哪些串口。
  2. VISA Configure Serial Port（配置参数）
    设置波特率(Baud Rate): 9600/19200/38400/115200；数据位(Data Bits): 8；停止位(Stop Bits): 1.0；校验(Parity): None；流控(Flow Control): None。这些参数必须和仪器设置完全一致。
  3. VISA Write（发送命令）
    写入缓冲区: 要发送的命令字符串。如 "*IDN?\n"（查询仪器身份，\n 是终止符）。
  4. VISA Read（读取返回数据）
    读取前先用 Bytes at Serial Port 检查缓存中有多少字节。把读取数设为这个值，确保一次读完所有响应。注意：Write 后要等一小段时间（Wait 100ms）再 Read，否则仪器还没返回数据就读会超时。
  5. VISA Close（关闭端口）
    必须执行！不关的话端口一直占用，下次打不开。所有步骤的 Error 簇串联，确保任何一步出错都能安全退出。
📌 完整串口通信代码流程：
VISA Open("COM3")
  → VISA Config(9600, 8, 1, None, None)
  → VISA Write("*IDN?\n")
  → Wait(100ms) // 等仪器响应
  → Bytes at Port 返回 N
  → VISA Read(N 字节)
  → VISA Close
// 所有步骤 Error 簇串联
串口调试最常见问题：① 波特率不匹配 ② COM口号错了 ③ 发送后没等就直接读 ④ 忘记 VISA Close 导致端口占用 ⑤ 终止符（\n vs \r）设置不一致。建议：先用 SSCOM 等通用串口工具确认硬件通信正常，再写 LabVIEW 程序。

14.3 SCPI 命令速查

命令功能仪器返回什么
*IDN?查询仪器身份制造商,型号,序列号,固件版本
*RST复位到出厂默认无返回

🏗 软件架构：状态机、生产者-消费者、QMH

▼

15.1 状态机 —— 最适合有步骤流程的程序

结构：While 循环 + Case 结构 + 移位寄存器（存当前状态枚举）。

📌 电池测试状态机：
Initialize（初始化仪器）
  → Idle（等待用户点"开始"）
    → CC_Charge（恒流充电，监控电压）
      → CV_Charge（恒压充电，监控电流）
        → Rest（静置30秒）
          → Discharge（恒流放电）
            → CheckLoop（还有下个循环?→CC_Charge : Done）
              → Save（保存数据）
                → Done（停止）

15.2 生产者-消费者 —— 界面永远不卡顿的秘密

两个并行循环 + 一个队列：

  • 生产者（Event 循环）：处理用户操作（点击按钮、修改参数），把命令通过 Enqueue 发送到队列。绝不执行耗时操作，界面永远流畅。
  • 消费者（工作循环）：从队列 Dequeue 取命令，执行耗时任务（仪器通信、数据采集、文件保存）。

15.3 QMH —— 工业级项目的事实标准

QMH = 队列 + 状态机 + 事件驱动。每个消息是一个字符串命令（可附带 Variant 数据），消费者用 Case 结构分发处理。可以扩展为多消费者：采集消费者、显示消费者、存储消费者各自一个循环。
