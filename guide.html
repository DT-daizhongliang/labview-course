🔰 认识 LabVIEW What is LabVIEW

▼

1.1 LabVIEW 是什么？What is LabVIEW?

LabVIEW（读作 /læbˈvjuː/「莱布维尤」）全称 Laboratory Virtual Instrument Engineering Workbench（实验室虚拟仪器工程工作台）。1986 年由美国 NI（National Instruments，美国国家仪器）公司发布。它不是普通的编程语言——它是一种图形化编程语言（Graphical Programming Language），NI 官方称之为 G 语言（G Language）。

🔑 核心认知：LabVIEW ≠ 传统编程

传统编程C / Python / Java / C#：你在文本编辑器里一行一行地敲代码——字母、数字、括号、分号。写错一个符号，程序报错。

LabVIEW：你在白色画布上拖放功能方块，然后用彩色的线把它们连起来。就像画电路图或流程图。你不写任何文字代码。

📐 图示：文本编程 vs 图形化编程
// C 语言
int a = 5;
int b = 3;
int c = a + b;
printf("%d", c);
VS
🟠 [数字A] ──橙色线──→ [ + ] ──橙色线──→ 🟠 [结果C]
🟠 [数字B] ──橙色线──↗
// 用连线代替文字代码

2.2 详细安装步骤Installation Steps

🌐 ni.com - NI Official Website🔴🟡🟢

📌 步骤 1：访问 NI 官网

浏览器输入 www.ni.com → 搜索框输入 "LabVIEW Community Edition download" → 点击搜索结果中标题含 "Download" 的链接。

💡 页面是全英文的，可使用浏览器翻译功能（右键→翻译成中文）

  1. 注册 NI 账号 Sign Up：下载页面会要求登录。点击 "Create an account" → 填写邮箱 Email、姓名 Name、密码 Password → 去邮箱点击 NI 发来的验证链接 Verify Email → 免费注册完成。
  2. 选择版本与下载：登录后在下载页面选择 LabVIEW Community Edition → 选操作系统为 Windows → 点击 Download。文件名类似 ni-labview-community-2023-x86.exe，约 2-3 GB。
  3. 双击运行安装包：找到下载好的 .exe 文件 → 双击 → 弹出 UAC 窗口点击「是 Yes」。
  4. 选择安装路径：建议使用默认路径：C:\Program Files\National Instruments\。不要改成中文路径！
  5. 勾选组件 Components（重要！）：☑ LabVIEW 主程序 ☑ NI-DAQmx（数据采集驱动 Data Acquisition Driver）☑ NI-VISA（仪器通信驱动 Instrument Communication Driver）☑ NI MAX（自动安装）
  6. 等待安装：约 20-60 分钟。中途可能弹出命令行窗口（不要关闭）和重启提示（正常重启后继续安装）。
  7. 激活 Activate：安装完成后从开始菜单启动 LabVIEW → 用 NI 账号登录即可激活社区版。

✍️ 第一个程序Your First VI: A+B=C

▼

4.1 目标 Goal

创建 VI：用户输入两个数字 → 自动计算两数之和 → 结果显示。走完 放控件→加函数→连线→运行 完整流程。

4.2 逐步骤操作Step-by-Step Instructions

Step 1：新建 VICreate New VI

  1. Getting Started 窗口 → 点击 Blank VI
  2. 两个窗口出现：灰色前面板 + 白色程序框图

Step 2：放输入控件Place Input Controls

🟫 Front Panel 前面板🔴🟡🟢
🔢 Numeric Control  数字 A ← 白色背景，可输入
🔢 Numeric Control  数字 B ← 同上
📊 Numeric Indicator 结果 C ← 灰色背景，只显示
  1. 灰色前面板右键 → Numeric → Numeric Control
  2. 点击放置 → 双击标签改名为 "数字 A"
  3. 重复：再放一个 → 改名为 "数字 B"
  4. 右键 → Numeric → Numeric Indicator → 改名为 "结果 C"

Step 3：切换到框图添加函数Switch to Block Diagram

  1. 按 Ctrl+E → 白色程序框图 → 看到 3 个对应端子（粗边框=输入源，细边框=输出目标）
  2. 右键 → Numeric → Add（+号三角形图标）→ 放置在输入输出之间

Step 4：连线Wire Them

📐 图示：连线流程 Wiring Flow
📥 数字A
Numeric Control
━━橙色线━━→
Orange Wire (DBL)
➕ Add
x+y=result
━━橙色线━━→
Orange Wire (DBL)
📤 结果C
Numeric Indicator
📥 数字B

  1. 鼠标移到「数字A」右侧小三角端子 → 光标变线轴图标（线圈）
  2. 按住鼠标左键拖动 → 橙色虚线跟随 → 拖到 Add 函数左上角 x 端子 → 松手
  3. 「数字B」→ Add 函数左下角 y 端子
  4. Add 右侧输出端子 →「结果C」输入端子
  5. 按 Ctrl+B 清除可能的断线。确认所有线都是实线（非虚线）

Step 5：整理、保存、运行Clean Up, Save & Run

  1. 点击工具栏 🧹 Clean Up Diagram → 自动整理
  2. Ctrl+S 保存，文件名："加法器.vi"
  3. Ctrl+R 运行 → 在「数字A」输入 8 →「数字B」输入 5 →「结果C」自动显示 13
  4. 试试小数：A=3.14, B=2.86 → C=6.00 ✅
🎉 完成！你做了：放控件(Place Controls)→加函数(Add Function)→连线(Wire)→运行(Run)。这就是所有 LabVIEW 程序的骨架。

5.2 布尔控件与机械动作Boolean Controls & Mechanical Action

🔑 机械动作 Mechanical Action —— 必须搞懂！

右键布尔控件 → Mechanical Action，6 种模式：

模式 Mode行为 Behavior适用场景
Latch When Released（松手复位）按下→松手→触发1次→自动弹回False「开始测试」按钮、「确认」按钮
Switch When Pressed（按下切换）按1次变True，再按1次变False，保持状态「手动/自动」开关
Switch Until Released（按住保持）按住= True，松开= False点动控制

🚨 Stop 按钮必须用 Latch 模式！否则按一次后停止端子永远是 True，程序再也跑不起来。

  • File Path Control文件路径控件：用户点击文件夹图标 → 弹出文件对话框 Browse Dialog → 选路径。常配合 File I/O 函数使用

6.2 字符串与枚举String & Enum

String 字符串（粉色连线 Pink Wire）：最常用函数：Concatenate Strings拼接、String Subset截取子串、Format Into String格式化、Scan From String解析提取。

Enum 枚举：用有意义的名字代替 0/1/2 数字表示状态。创建方法：右键前面板→List & Table→Enum→右键 Edit Items→添加条目。配合 Case Structure 使用，每个枚举值一个分支。强烈推荐使用枚举代替整数表示状态！

6.3 类型转换Type Conversion

连接不同数值类型时出现红色小三角 Coercion Dot——LabVIEW 自动帮你转换类型。DBL→I32 会截断小数！用 Numeric→Conversion 子选板中的转换函数显式转换更安全。

7.1 数据流规则Dataflow Rules

🔑 黄金规则 Golden Rule：一个节点在所有输入端都收到数据后才开始执行。

  • 有连线依赖 → 顺序执行Sequential
  • 无限连依赖 → 并行执行Parallel (No extra code needed!)

7.2 控制执行顺序的三种方法Three Ways to Control Order

📐 图示：数据流中的顺序控制
🥇 Method 1: Data Dependency 数据依赖 — [A]━━数据线━━→[B] A先于B
🥈 Method 2: Error Chain 错误链 — [A]━━ErrOut→ErrIn━━[B] 推荐！
🥉 Method 3: Flat Sequence 顺序结构 — [Frame0|Frame1|Frame2] 不得已才用

8.2 Case Structure & Event Structure条件结构 & 事件结构

Case Structure：选择器接布尔→True/False 两分支；接枚举→每个值一个分支（最推荐！）。务必设 Default 分支。
Event Structure：必须放在 While 循环内部！等待用户界面事件（Value Change/Panel Close?/Timeout）。不在 Event 里放耗时操作——只发消息。

8.3 移位寄存器Shift Register

循环边框右键 → Add Shift Register。左侧↓=上次输出Previous value，右侧↑=本次传给下次Next value。经典应用：累加器 Accumulator、状态机 State Machine 存储当前状态。

  2. While Loop + Stop Button：持续运行程序
  3. Case Structure + Enum：实现状态切换
  4. Event Structure + While：响应按钮点击

🧱 子 VI SubVI & Modular Programming

▼

11.1 什么是 SubVI？What is a SubVI?

SubVI = LabVIEW 中的「函数 Function」。封装常用功能到独立 .vi 文件，拖入任意 VI 即可调用。类比：Python def func():、C void func(){}。

11.2 创建 SubVI 6 步流程6-Step Creation Process

  1. 写功能 Build Functionality：在一个 VI 中把功能调通，确保正确
  2. 设连接器 Connector Pane：右上角小图标右键→Show Connector。选 4-2-2-4 布局。分配原则：左上=输入 Input，右上=输出 Output，左下=Error In，右下=Error Out
  3. 绑定端子 Assign Terminals：点击连接器格子(变黑)→点击前面板对应控件，颜色变化确认绑定
  4. 编辑图标 Edit Icon：右上角图标右键→Edit Icon。4-6字概括+简单图形
  5. 写文档 Documentation：File→VI Properties→Documentation，写清功能和参数。Ctrl+H 时会显示
  6. 保存命名 Save：有意义文件名如 "Convert_C_to_F.vi"，不用 "subvi_03.vi"

11.3 设计铁律Design Rules

  1. 必须有 Error In/Out：无例外。LabVIEW 通信协议
  2. 单一职责 Single Responsibility：一个SubVI只做一件事
  3. 有意义的文件名：看名知义
  4. 输入给默认值 Default Values：未连线也能运行

✏️ 动手练习

  1. 创建「摄氏↔华氏」双向转换两个 SubVI，带 Error In/Out
  2. 创建「计算数组平均值」SubVI
  3. 在主 VI 中调用这些 SubVI，验证功能

14.1 VISA 五步法VISA 5-Step Method

📐 图示：VISA 串口通信标准流程
① VISA Open("COM3") → 打开串口 Open Port
② VISA Config(9600,8,1,None) → 配置参数 Configure

15.3 QMHQueued Message Handler

16.2 10 步开发流程10-Step Development Process

  1. 需求文档 Requirement Doc：明确测试参数(电压/电流/容量/循环)、精度、报告格式。书面确认
  2. 硬件选型 Hardware Selection：电源型号、负载型号、DAQ型号、通信方式确定
  3. 架构设计 Architecture Design：选择 QMH，定义消息类型 Message Types 和状态流转
  4. UI 设计 Interface Design：参数区←左、数据显示←中、曲线←右、按钮←底
  5. 底层驱动 Low-level Drivers：电源控制 SubVI、负载控制 SubVI、DAQ采集 SubVI。每个带 Simulation 模式
  6. 核心逻辑 Core Logic：实现状态机(CC_Charge→CV_Charge→Rest→Discharge→Loop)
  7. 数据处理 Data Processing：容量积分 Ah=∫I·dt、能量 Wh=∫V·I·dt、异常检测(过压/过流/过温)
  8. 数据存储 Data Storage：CSV + TDMS 双格式，加属性标注
  9. 测试验证 Testing：模拟模式→真硬件→边界测试→24h 长时运行
